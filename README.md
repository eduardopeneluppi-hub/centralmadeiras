# Central Madeiras

Site institucional da Central Madeiras, construído com React + Vite + Tailwind CSS.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion (animações)

## Rodando localmente

```bash
npm install
npm run dev
```

## Estrutura

- `src/Intro.jsx` — tela de abertura animada
- `src/Navbar.jsx` — navbar estilo "dynamic island"
- `src/BannerRotator.jsx` — carrossel de banners na hero
- `src/Catalog.jsx` — fileira de produtos do catálogo
- `src/Origin.jsx` — mapa animado de rastreabilidade da madeira
- `src/Testimonials.jsx` — carrossel de depoimentos
- `src/ProjectChat.jsx` — chat estilo iPhone para descrever o projeto
- `src/QuoteModal.jsx` — modal flutuante de solicitação de orçamento (WhatsApp)
